# Talentry

**Donde tu talento encuentra oportunidades.**

Talentry es un proyecto académico de plataforma web para conectar estudiantes, jóvenes profesionales y empresas.

## Cómo abrirlo

- Abre `index.html` para ver la página principal.
- Las páginas interiores están en `paginas/` y comparten navegación, pie de página, modo claro/oscuro y diseño adaptable.
- `app.html` contiene el acceso/registro y el panel de cuenta conectado a Firebase. Para utilizar autenticación y datos reales, la configuración y las reglas de Firebase deben estar habilitadas.

## Páginas incluidas

- Inicio (`index.html`)
- Cómo funciona
- Oportunidades (búsqueda y filtros locales con vacantes demostrativas)
- Beneficios
- Talento
- Empresas
- Innovación
- Contacto (formulario demostrativo; no envía datos a un servidor)
- Mi cuenta (`app.html`)

## Tecnologías

HTML5, CSS3, JavaScript, Font Awesome, Google Fonts, Firebase Authentication y Cloud Firestore.

## Nota académica

Las cifras, empresas, vacantes y testimonios que aparecen como ejemplos son demostrativos. Las funciones de cuenta dependen de la configuración de Firebase.
